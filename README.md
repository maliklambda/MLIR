# AI from scratch in Rust
This recreational programing session is about learning how AI works within a weekend.
The goal is about going from a rough, superficial understanding to deeply rooted foundational knowledge.
This is a journey from a single artificial neuron to a LLM.

## Artificial Neurons
[source](https://towardsdatascience.com/explain-like-im-five-artificial-neurons-b7c475b56189/)<br>
An artificial neuron is the building block of any AI.
It has three parts: 
1. An array of weighted inputs
2. A transfer function
3. An activation function

A neuron takes some input and produces an output.
